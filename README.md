# Waterplane: Harbor Run

Side-scrolling Android game. You fly the waterplane logo (the chevron plane) through storm clouds, rock spires, lighthouses and reefs.

- **Hold** to climb. Climbing burns **TOKENS**.
- **Release** to glide.
- **Skim the water gently** to refill tokens. Hit it too steep and you sink.
- Grab the blinking amber cursors for tokens and score.
- Difficulties: Easy / Normal / Hard (speed, gap size, fuel burn, crash tolerance). Level 1 is "Harbor Run". Stars depend on how many cursors you collect.

Build (no Gradle, just Android SDK build-tools 35 + platform 35): `./build.sh` → `build/waterplane-game-<version>.apk`
