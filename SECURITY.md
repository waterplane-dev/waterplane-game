# Security

The game has no internet permission, no accounts and no server. It stores only your best scores and the last difficulty you picked, in the app's private storage.

## Reporting

Please report privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue for it.

This is a one-person hobby project. Expect a first answer within a couple of weeks.

## Supported versions

Only the latest release.
